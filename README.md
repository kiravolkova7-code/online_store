# Online Store
## Описание:
Данный проект представляет собой ядро для простого интернет-магазина. 
Проект реализует два основных класса: Product (товар) и Category (категория),
а также механизм для загрузки каталога из JSON-файла.
## Функционал:
### V.14-1
* Реализованы классы `Product` и `Category` с необходимыми атрибутами 
(name, description, price, quantity для товара; name, description, products для категории).
* Класс `Category` отслеживает общее количество созданных категорий и товаров 
во всей системе через атрибуты класса `category_count` и `product_count`.
* Функция `load_categories_from_json(file_path)` считывает данные о категориях и товарах 
из файла формата JSON и автоматически создает соответствующие объекты Python.
### V.14-2
* В классе `Category` список товаров (products) сделан приватным атрибутом (__products), 
чтобы запретить прямой доступ извне.
* Реализован метод `add_product(self, product)`, который позволяет добавлять товары в категорию 
только через этот публичный интерфейс с проверкой типа объекта.
* Добавлен геттер `@property def products(self)`, позволяющий получать доступ 
к приватному списку товаров как к свойству `.products`.
* Метод `get_products()` теперь формирует и возвращает список отформатированных 
строк для вывода информации о товарах.
* В класс `Product` добавлен класс-метод `new_product(cls, product_data: dict)`. 
Он принимает словарь с параметрами товара и возвращает новый экземпляр класса Product.
* Атрибут цены (price) в классе `Product` сделан приватным (__price).
Описаны геттер и сеттер с помощью декоратора `@property`. Сеттер проверяет положительное 
ли значение.
### V.15-1
* Метод `__str__` возвращает строку в формате "Название продукта, цена руб. Остаток: количество шт.", 
используя уже существующие атрибуты объекта.
* Для класса `Category`: Метод `__str__` должен показывать название категории и общее количество всех единиц товара внутри неё.
* Реализован метод `__add__(self, other)`. Он проверяет, является ли второй операнд объектом `Product`. 
Если да, он вычисляет суммарную стоимость товаров на складе по формуле 
`(цена_первого * кол-во_первого) + (цена_второго * кол-во_второго)` и возвращает результат как число.
### V.16-1
* В систему были добавлены два специализированных класса-наследника от базового класса `Product`: 
`Smartphone` (Смартфон) и `LawnGrass` (Газонная трава).
* Доработана функциональность метода `__add__` в классе `Product`. Ранее она позволяла складывать стоимость любых товаров, 
даже если они относились к разным категориям (например, смартфон и газонная трава).
* Метод `add_product` в классе `Category` был усилен дополнительной проверкой типов. Теперь он принимает только те объекты,
которые являются экземплярами класса `Product` или его наследников.
### V.16-2
* Логирование создания: При создании любого объекта классов `Product`, `Smartphone` или `LawnGrass`
в консоль будет выведено сообщение. 
* Теперь нельзя создать экземпляр `BaseProduct` напрямую, что является правильным поведением для абстрактного класса. 
Все конкретные товары обязаны реализовывать его интерфейс.

## Зависимости:
Для работы и тестирования проекта требуется библиотека pytest. 
Она используется для запуска модульных тестов.
Установка зависимостей:
```
pip install pytest
```
## Тестирование:
Качество кода проверяется с помощью модульных тестов, написанных с использованием фреймворка `pytest`.
Тесты находятся в директории `tests/`.
Чтобы запустить тесты, выполните команду в корневой директории проекта:
```
pytest
```
Тестовый набор покрывает следующие сценарии:

* Корректная инициализация объектов класса Product.
* Корректная инициализация объектов класса Category.
* Правильный подсчет общего количества продуктов `(Category.product_count)`.
* Правильный подсчет общего количества категорий `(Category.category_count)`.
* Проверяет что класс-метод `new_product` успешно создает объект `Product`, корректно распаковывая 
данные из словаря и присваивая их атрибутам (name, description, price, quantity).
* Проверяет установку корректной цены.
* Проверяет защиту от установки некорректной цены (<= 0).
* Проверяет успешное добавление товара в категорию.
* Проверяет обработку ошибки при добавлении неверного типа данных.
* Проверяет работу геттера для получения списка товаров.
* Проверяет форматирование строк в методе get_products.
* Проверяет строковое представление товара `(__str__)`.
* Проверяет сложение стоимости двух товаров `(__add__)`.
* Проверяет, что при сложении с неподдерживаемым типом вызывается `TypeError`.
* Проверяет строковое представление категории с товарами.
* Проверяет, что объект класса `Smartphone` корректно инициализируется.
* Проверяет, что объект класса `LawnGrass` корректно инициализируется.
* Проверяет, что операция сложения работает корректно для объектов одного класса.
* Проверяет, что валидный объект товара успешно добавляется в категорию.
* Проверяет, что попытка добавить в категорию объект неверного типа (строку) 
приводит к возникновению ошибки `TypeError`. 
* Проверка: миксин `CreationLoggerMixin` правильно запоминает именованные аргументы.
* Проверка: нельзя создать экземпляр абстрактного класса `BaseProduct`.

## Использование:
Вы можете запустить встроенный пример, который загружает данные из data/products.json 
и выводит их на консоль, находится в модуле `main.py`. В консоли введите команду:
```
 python main.py
```
Также Вы можете запустить встроенный пример, который не загружает данные, а вводит их. 
Находится в модуле `16.2_main.py`. В консоли введите команду:
```
 python 16.2_main.py
```
Этот скрипт выведет список всех загруженных категорий с товарами и общую статистику.
